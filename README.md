Intelligentes Wecksystem
Smart Alarm System based on Arduino Uno.
Projektbeschreibung
Das intelligente Wecksystem erkennt mithilfe eines Ultraschallsensors, ob sich eine Person noch im Bett befindet.
Solange die Person erkannt wird, aktiviert das System:
LCD-Anzeige
Buzzer-Wecksignal
Rote LED
Sobald die Person aufsteht, wechselt das System in den Erfolgsmodus:
Grüne LED aktiviert
Erfolgsmelodie wird abgespielt
Temperatur wird auf dem LCD angezeigt
Verwendete Komponenten
Arduino Uno
HC-SR04 Ultraschallsensor
LCD Display 16x2
Buzzer
LED Rot
LED Grün
Temperatursensor
